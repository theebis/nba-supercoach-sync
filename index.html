Projections
SCHOOPS projects points per game from recent form, price and SuperCoach's projection, then multiplies by the games each player is actually expected to play (injuries, rest). Tested on every finished round, it misses by less than SuperCoach's own projections. Used for projected price changes, the optimiser and the Trade Advisor.
Visit counting
SCHOOPS counts visits anonymously (no cookies, nothing personal) to see which pages get used. Choose "Don't count me" in each browser you use if you run the site.
Est. Magic Number
Dollars per point-per-game. Each game played moves a player's price 4.15% of the way to magic × his per-game average over the last two rounds; no games, no change. Fitted to 1,231 real SuperCoach price changes. Breakevens are round totals over this round's games.
